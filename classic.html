東京車站周邊：三種免費地圖函式庫

同一組資料（9 個地點、一條步行路線、一圈 500 公尺範圍），分別用 Leaflet、MapLibre GL JS、OpenLayers 畫出來。三者都免費、不需要 API 金鑰。點地圖上的圓點可看地點名稱。

中心點：東京車站丸之內站舍 35.6812°N, 139.7671°E
車站・交通 景點 購物・商場 步行路線：車站 → 行幸通 → 皇居外苑 車站 500 m 範圍

① Leaflet

v1.9.4 · 點陣圖磚

最輕量、最好上手。底圖是 OpenStreetMap 的圖片圖磚，右上角可切換圖層開關。

核心程式碼 
const map = L.map('map').setView([35.6812, 139.7671], 16);
L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
  attribution: '© OpenStreetMap'
}).addTo(map);
L.circleMarker([35.6812, 139.7671], { color: '#1f5fbf' })
 .bindPopup('東京車站').addTo(map);
L.circle([35.6812, 139.7671], { radius: 500, fillOpacity: 0.06 }).addTo(map);

② MapLibre GL JS

v4.7.1 · 向量圖磚 + 3D

用 WebGL 繪製，縮放平滑。這張開啟 3D 建築，按住右鍵（手機用兩指）拖曳可旋轉、傾斜視角。

核心程式碼 
const map = new maplibregl.Map({
  container: 'map',
  style: 'https://tiles.openfreemap.org/styles/liberty',
  center: [139.7671, 35.6812],   // 注意：經度在前
  zoom: 15.6, pitch: 55
});
new maplibregl.Marker({ color: '#1f5fbf' })
  .setLngLat([139.7671, 35.6812])
  .setPopup(new maplibregl.Popup().setText('東京車站'))
  .addTo(map);

③ OpenLayers

v9.2.4 · 專業 GIS

功能最完整，支援各種座標系統與 GIS 格式。座標要先用 fromLonLat 轉成網頁麥卡托投影。

核心程式碼 
const map = new ol.Map({
  target: 'map',
  layers: [ new ol.layer.Tile({ source: new ol.source.OSM() }) ],
  view: new ol.View({
    center: ol.proj.fromLonLat([139.7671, 35.6812]),
    zoom: 16
  })
});
const pt = new ol.Feature(new ol.geom.Point(ol.proj.fromLonLat([139.7671, 35.6812])));
map.addLayer(new ol.layer.Vector({ source: new ol.source.Vector({ features: [pt] }) }));
