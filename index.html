東京車站手繪地圖

把同一組資料（9 個地點、一條步行路線、500 公尺範圍）用三套免費函式庫畫成手繪風格：底圖泛黃、線條微微抖動、加上紙張顆粒，標記用 Rough.js 畫成鉛筆塗鴉。點標記可看地點名稱，用上方的「細節等級」切換 1～5 級。

① Leaflet

點陣圖磚 + CSS 濾鏡

點陣圖磚套上「泛黃 + 抖動 + 紙紋」濾鏡；路線所在的圖層只加抖動，標記和文字保持清楚。點一下地圖後才能用滾輪縮放。

手繪關鍵程式碼 
/* CSS：只對底圖圖層套濾鏡 */
.leaflet-tile-pane   { filter: url(#paper) sepia(.5) saturate(.7); }
.leaflet-overlay-pane{ filter: url(#ink); }

// JS：用 Rough.js 畫出塗鴉圓點，當成 divIcon
const svg = document.createElementNS(NS, 'svg');
svg.appendChild(rough.svg(svg).circle(15, 15, 22, {
  fill: '#3f7a3a', fillStyle: 'hachure', roughness: 1.4
}));
L.marker([lat, lng], { icon: L.divIcon({ html: svg.outerHTML }) }).addTo(map);

② MapLibre GL JS

向量圖磚重新上色

向量底圖可以逐層改顏色：道路改成米白配咖啡色邊線、水改成水彩藍、建築改成牛皮紙色，3D 建築也一起換色。按住右鍵（手機用兩指）拖曳可以旋轉、傾斜。

手繪關鍵程式碼 
map.on('load', () => {
  for (const layer of map.getStyle().layers) {
    if (layer.type === 'background')
      map.setPaintProperty(layer.id, 'background-color', '#efe5cc');
    if (layer.type === 'fill' && /water/.test(layer.id))
      map.setPaintProperty(layer.id, 'fill-color', '#9cc3cf');
    if (layer.type === 'symbol')
      map.setPaintProperty(layer.id, 'text-color', '#3a2e24');
  }
});

③ OpenLayers

分層 className + 畫布文字

用 className 把底圖、線條、標記拆成三張畫布，分別套不同濾鏡；地名直接用手寫字體畫在畫布上。按住 Ctrl（Mac 用 ⌘）再滾動滑鼠滾輪可以縮放。

手繪關鍵程式碼 
new ol.layer.Tile({ source: new ol.source.OSM(), className: 'ol-paper' });
new ol.layer.Vector({ source: lines,  className: 'ol-ink'  });
new ol.layer.Vector({ source: points, className: 'ol-pins' });

// 標記：Rough.js 畫的 SVG 轉成圖片，文字用手寫字體
new ol.style.Style({
  image: new ol.style.Icon({ src: 'data:image/svg+xml,' + encodeURIComponent(svg) }),
  text:  new ol.style.Text({ text: '東京車站', font: '700 15px "LXGW WenKai TC"' })
});
